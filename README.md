# SoundPalestine

منصة صوتية عامة: الجميع يستطيع الاستماع، والمستخدم المسجل يرفع الملفات بعد تسجيل الدخول باسم مستخدم وكلمة مرور. ملفات المستخدمين تمر بمراجعة الأدمن، بينما ملفات الأدمن تنشر مباشرة.

## ما هو جاهز

- مكتبة عامة مفتوحة للاستماع دون حساب.
- تسجيل وإنشاء حساب باسم مستخدم + كلمة مرور فقط.
- دعم أسماء مستخدمين عربية وإنجليزية.
- رفع الصوت مباشرة إلى Supabase Storage دون تمرير الملف الكبير عبر Vercel.
- حد أولي 50MB للملف.
- المستخدم يرى ملفاته وحالتها: pending / published / rejected.
- لوحة أدمن للاستماع للملفات المنتظرة واعتمادها أو رفضها أو حذفها.
- الأدمن يستطيع الرفع والنشر مباشرة.
- مكان اللوجو Placeholder حتى يتم توفير الشعار النهائي.
- RLS وسياسات Storage تمنع المستخدم العادي من تجاوز المراجعة ونشر ملفه مباشرة.

## الإعداد

1. أنشئ مشروع Supabase مستقلًا باسم SoundPalestine.
2. طبّق الملف `supabase/migrations/001_soundpalestine.sql` على ذلك المشروع فقط.
3. ضع القيم التالية في Vercel والبيئة المحلية:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
SUPABASE_SERVICE_ROLE_KEY=
```

4. سجّل أول حساب من واجهة الموقع.
5. رقِّ الحساب الأول إلى أدمن من SQL Editor:

```sql
update public.profiles
set role = 'admin'
where username = 'اسم_المستخدم';
```

6. شغّل `npm install` ثم `npm run build`.

## ملاحظة تسجيل الدخول

المستخدم لا يحتاج بريدًا ولا يراه. التطبيق يحول اسم المستخدم داخليًا إلى بريد تقني مشتق بتجزئة SHA-256 فقط للاستفادة من أمان Supabase Auth في حفظ كلمات المرور والجلسات. هذا البريد الداخلي ليس جزءًا من تجربة المستخدم.
